# ITA Manager Plugin

Plugin WordPress สำหรับจัดการข้อมูล **การประเมินคุณธรรมและความโปร่งใส (ITA)** ของหน่วยงาน  
รองรับหลายปีงบประมาณ จัดการข้อมูลทั้งหมดในหน้า Admin หน้าเดียว

---

## การติดตั้ง

1. นำโฟลเดอร์ `ita-manager/` ไปวางใน `wp-content/plugins/`
2. เปิดใช้งาน Plugin ใน **WordPress Admin → Plugins**
3. ระบบจะสร้างตารางฐานข้อมูลให้อัตโนมัติ (4 ตาราง: `ita_years`, `ita_indicators`, `ita_moits`, `ita_items`)

---

## การใช้งาน Admin

เข้าที่ **WordPress Admin → ITA Manager**

### 1. เพิ่มปีงบประมาณ
- กดปุ่ม **"เพิ่มปีงบประมาณ"** ด้านขวาบน
- กรอกปี เช่น `2569`
- บันทึก → แท็บปีจะปรากฏด้านบน

### 2. เพิ่มตัวชี้วัด
- คลิกแท็บปีที่ต้องการ
- กดปุ่ม **"เพิ่มตัวชี้วัด"**
- กรอกลำดับที่และชื่อ เช่น: `4` / `การส่งเสริมความโปร่งใส`

### 3. เพิ่ม MOIT
- คลิกที่การ์ดตัวชี้วัด → กด **"เพิ่ม MOIT"**
- กรอกหมายเลข MOIT และชื่อ

### 4. เพิ่มรายการภายใน MOIT

รายการมี 2 ประเภท:

#### 📋 รายการปกติ
ใช้สำหรับรายการเอกสารที่มีเลขข้อ เช่น `10.1`, `10.2.1`
- **ข้อที่**: กรอกเลขลำดับ → ระบบจะแสดงการย่อหน้าอัตโนมัติตามจำนวนจุด
  - `10.1` → ระดับที่ 1 (ปกติ)
  - `10.2.1` → ระดับที่ 2 (ย่อหน้า 1 ระดับ)
  - `10.2.1.1` → ระดับที่ 3 (ย่อหน้า 2 ระดับ)
- **รายละเอียด**: คำอธิบายเอกสาร
- **ไฟล์แนบ**: เลือกจาก Media Library หรือวาง URL
- **ลิงค์ภายนอก**: URL ภายนอก (ใช้เมื่อไม่มีไฟล์)

#### 🏷️ หัวข้อ / ช่วงเวลา
ใช้สำหรับแบ่งกลุ่มรายการ เช่น `ไตรมาส 3`, `รอบ 6 เดือน`, `รอบ 12 เดือน`
- **ข้อที่ / ลำดับ**: ข้อความเต็ม เช่น `ไตรมาส 3` หรือเว้นว่างก็ได้
- **รายละเอียด**: คำอธิบายเพิ่มเติม (ไม่บังคับ)
- ไม่มีช่องไฟล์/ลิงค์
- แสดงเป็นแถบสีน้ำเงินคั่นระหว่างกลุ่มรายการ

## การแสดงผลหน้าเว็บ (Shortcode)

วาง Shortcode ในหน้า WordPress ที่ต้องการแสดงข้อมูล ITA:

```
[ita_display]
```
→ แสดงทุกปีงบประมาณ แบบ Tab สลับไปมา

```
[ita_display year="2569"]
```
→ แสดงเฉพาะปี 2569 (ไม่มีแท็บ)

### ลักษณะการแสดงผลหน้าเว็บ
- **แท็บปี** → คลิกสลับระหว่างปีงบประมาณ
- **ตัวชี้วัด** → คลิกเพื่อขยาย/ยุบ
- **MOIT** → คลิกเพื่อขยาย/ยุบ
- **รายการ**: แสดงเลขข้อ + รายละเอียด + ปุ่มดูไฟล์/ลิงค์
- **หัวข้อ**: แสดงเป็นแถบสีคั่นกลุ่ม
- **รายการย่อย** (มีจุด 2 ระดับ): ย่อหน้าอัตโนมัติ

## ตารางฐานข้อมูล

| ตาราง | คอลัมน์สำคัญ |
|-------|-------------|
| `tm_ita_years` | `id`, `year_label` (เช่น 2569), `sort_order` |
| `tm_ita_indicators` | `id`, `year_id`, `indicator_no`, `title` |
| `tm_ita_moits` | `id`, `indicator_id`, `moit_no`, `title` |
| `tm_ita_items` | `id`, `moit_id`, `item_type` (item/section), `item_no`, `title`, `file_id`, `file_url`, `link_url` |

## Security

- ทุก AJAX request ตรวจสอบ **WordPress Nonce** (`ita_manager_nonce`)
- ตรวจสอบสิทธิ์ **`manage_options`** (Admin เท่านั้น)
- ข้อมูลทุกฟิลด์ผ่านการ sanitize ก่อนบันทึก (`sanitize_text_field`, `wp_kses_post`, `esc_url_raw`)
- URL ที่แสดงผลหน้าเว็บผ่าน `esc_url()`
